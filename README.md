# TU Room & Study Radar (`tu-room-radar`)

> Community plugin for [TU Cockpit](https://github.com/tu-cockpit-community/TU-Cockpit)

Find free lecture halls, quiet study spots, and navigate campus rooms across Freihaus, Karlsplatz, and Gußhaus.

## Features
- **Live Free Lecture Hall Finder:** See which lecture halls are currently available between courses for studying.
- **Quiet Study Zones:** Direct directions to library learning spaces and silent cubicles.
- **Room Code Resolver:** Quick lookup for room codes (e.g., EI 7, HS 1, Boecklsaal).
- **Zero-Dependency Single-File Bundle:** Compiled into a single HTML bundle via `vite-plugin-singlefile`.
